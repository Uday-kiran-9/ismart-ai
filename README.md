# 🚀 iSmart AI

iSmart AI is a modern, frontend-based AI tools discovery platform that helps users explore, compare, and choose the best AI tools for their needs.

Built with a focus on clean UI, usability, and performance, it provides a centralized place to discover trending AI tools across different categories.

---

## ✨ Features

- 🔍 **Smart Search**
  - Search tools by name, category, description, or tags

- 📂 **Categorized Browsing**
  - Tools grouped into categories like Chatbots, Coding, Design, Writing, etc.

- 🤖 **AI Tool Recommendation**
  - Get top 3 tools based on selected task (coding, writing, design)

- ⚖️ **Compare Tools**
  - Side-by-side comparison of two tools with ratings

- ❤️ **Favorites System**
  - Save tools using localStorage

- 🧠 **Tool Details Modal**
  - View detailed info with ratings and direct links

- 🎨 **Premium UI/UX**
  - Dark theme with glassmorphism
  - Gradient accents and smooth animations
  - Fully responsive design

---

## 🛠️ Tech Stack

- HTML5  
- Tailwind CSS  
- Vanilla JavaScript  

---

## 📊 How It Works

- Tools are stored as structured data (`data.js`)
- UI is dynamically rendered using JavaScript
- Recommendation system:
  - Filters tools based on selected task
  - Sorts using rating metrics
  - Displays top results
- Search:
  - Matches across name, description, category, and tags
- Favorites:
  - Stored in browser using `localStorage`

---

## 🎯 Problem Solved

With hundreds of AI tools available, users often struggle to decide which tool to use for a specific task.

iSmart AI solves this by:
- Organizing tools into categories  
- Providing clear descriptions and ratings  
- Offering recommendations based on user needs
